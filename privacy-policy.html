개인정보처리방침

최종 수정일: 2026년 1월 5일

중요: 본 앱은 골프 기록 데이터를 사용자의 기기에만 저장합니다. 다만, 앱 사용 패턴 분석을 위해 Firebase Analytics를 사용하여 익명화된 사용 통계를 수집합니다.

1. 개인정보의 수집 및 이용

진심골퍼 스코어카드(이하 "본 앱")는 다음과 같이 개인정보를 처리합니다:

1.1 로컬 저장 데이터 (기기 내부에만 저장)

  • 수집하는 정보: 골프 라운드 기록, 홀별 상세 기록, 앱 설정
  • 외부 전송: 없음
  • 저장 위치: 사용자 기기 내부 저장소에만 저장

1.2 Firebase Analytics를 통한 사용 통계 수집

수집 목적: 앱 개선 및 사용자 경험 향상

수집하는 정보:

  • 앱 사용 패턴 (화면 조회, 기능 사용 빈도)
  • 기기 정보 (OS 버전, 기기 모델, 언어 설정)
  • 앱 성능 데이터 (오류 발생, 앱 실행 시간)
  • 익명화된 사용자 ID (Firebase에서 자동 생성)
  • 일반적인 골프 통계 (라운드 수, 평균 스코어 등 - 개인 식별 불가)

수집하지 않는 정보:

  • 이름, 이메일, 전화번호 등 개인 식별 정보
  • 정확한 위치 정보
  • 구체적인 골프장 이름이나 개인 메모 내용

2. 앱에서 생성되는 데이터

본 앱은 사용자가 입력한 다음 정보를 사용자 기기에만 저장합니다:

  • 골프 라운드 기록 (날짜, 골프장명, 스코어)
  • 홀별 상세 기록 (Par, Score, Putt, Fairway, GIR, Hazard, Bunker, Penalty, 메모)
  • 앱 설정 정보 (언어 설정 등)

위 골프 기록 데이터는 절대 외부로 전송되지 않으며, 오직 사용자의 기기 내부에만 저장됩니다.

3. 제3자 제공

본 앱은 다음의 경우를 제외하고 사용자의 정보를 제3자에게 제공하지 않습니다:

  • Firebase Analytics (Google): 앱 사용 통계 분석 목적
    • 제공되는 정보: 익명화된 사용 패턴, 기기 정보, 일반적인 통계
    • 개인 식별 정보는 제공되지 않음
    • Google의 개인정보처리방침 적용: https://policies.google.com/privacy

4. 개인정보의 보유 및 이용 기간

  • 로컬 데이터: 사용자가 앱을 삭제할 때까지 기기에 보관됩니다.
  • Analytics 데이터: Firebase에서 최대 14개월간 보관 후 자동 삭제됩니다.
  • 앱을 삭제하면 기기의 모든 로컬 데이터가 함께 삭제됩니다.
  • 사용자는 앱 내에서 언제든지 개별 기록을 삭제할 수 있습니다.

5. 개인정보의 파기

  • 앱 삭제 시 기기의 모든 로컬 데이터가 자동으로 삭제됩니다.
  • 개별 기록은 앱 내에서 직접 삭제할 수 있습니다.
  • Firebase Analytics 데이터는 14개월 후 자동 삭제됩니다.

6. 사용자의 권리

사용자는 다음과 같은 권리를 가집니다:

  • 앱 내에서 언제든지 자신의 골프 기록을 조회할 수 있습니다.
  • 앱 내에서 언제든지 데이터를 수정하거나 삭제할 수 있습니다.
  • 앱을 삭제하여 모든 로컬 데이터를 완전히 제거할 수 있습니다.
  • 기기 설정에서 Analytics 추적을 비활성화할 수 있습니다 (광고 ID 재설정).

7. 개인정보의 안전성 확보 조치

  • 골프 기록 데이터는 사용자 기기의 내부 저장소에만 저장됩니다.
  • Firebase Analytics는 Google의 보안 프로토콜을 따릅니다.
  • 전송되는 Analytics 데이터는 암호화됩니다.
  • 개인 식별 정보는 수집하지 않습니다.
  • 기기의 보안 설정(잠금 화면 등)에 따라 보호됩니다.

8. 인터넷 권한

본 앱은 다음 목적으로 인터넷 권한을 사용합니다:

  • Firebase Analytics: 익명화된 사용 통계 전송
  • 향후 기능: 클라우드 백업 등 (선택적 기능으로 제공 예정)

골프 기록 데이터는 인터넷을 통해 전송되지 않습니다.

9. Analytics 추적 거부

사용자는 다음 방법으로 Analytics 추적을 제한할 수 있습니다:

  • Android: 설정 > Google > 광고 > 광고 ID 재설정
  • iOS: 설정 > 개인정보 보호 > 추적 > 앱이 추적을 요청하도록 허용 끄기

10. 개인정보처리방침의 변경

  • 본 개인정보처리방침은 법령 및 서비스 변경에 따라 수정될 수 있습니다.
  • 변경 시 앱 업데이트 공지를 통해 알려드립니다.
  • 중요한 변경사항은 최소 7일 전에 사전 공지합니다.

Privacy Policy

Last Updated: January 5, 2026

Important: This app stores your golf records only on your device. However, we use Firebase Analytics to collect anonymized usage statistics for app improvement.

1. Information Collection and Use

Serious Golfer's Scorecard ("the App") handles information as follows:

1.1 Local Storage Data (Stored Only on Device)

  • Information Collected: Golf round records, hole-by-hole details, app settings
  • External Transmission: None
  • Storage Location: Only on user's device internal storage

1.2 Usage Statistics via Firebase Analytics

Collection Purpose: App improvement and user experience enhancement

Information Collected:

  • App usage patterns (screen views, feature usage frequency)
  • Device information (OS version, device model, language settings)
  • App performance data (errors, app runtime)
  • Anonymized user ID (automatically generated by Firebase)
  • General golf statistics (round count, average scores, etc. - non-identifiable)

Information NOT Collected:

  • Personal identifiable information (name, email, phone number)
  • Precise location data
  • Specific golf course names or personal notes

2. Data Generated by the App

The app stores the following user-entered information only on the user's device:

  • Golf round records (date, golf course name, scores)
  • Hole-by-hole details (Par, Score, Putt, Fairway, GIR, Hazard, Bunker, Penalty, Notes)
  • App settings (language preferences, etc.)

This golf record data is never transmitted externally and is stored only on the user's device.

3. Third-Party Sharing

The app does not share user information with third parties except:

  • Firebase Analytics (Google): For app usage statistics analysis
    • Shared information: Anonymized usage patterns, device info, general statistics
    • No personal identifiable information is shared
    • Subject to Google's Privacy Policy: https://policies.google.com/privacy

4. Data Retention

  • Local Data: Retained on device until app is uninstalled
  • Analytics Data: Automatically deleted after 14 months by Firebase
  • Uninstalling the app will delete all local data
  • Users can delete individual records at any time within the app

5. Data Deletion

  • All local data is automatically deleted when the app is uninstalled
  • Individual records can be deleted directly within the app
  • Firebase Analytics data is automatically deleted after 14 months

6. User Rights

Users have the following rights:

  • View your golf records at any time within the app
  • Modify or delete your data at any time within the app
  • Completely remove all local data by uninstalling the app
  • Disable Analytics tracking in device settings (reset advertising ID)

7. Security Measures

  • Golf record data is stored only in the device's internal storage
  • Firebase Analytics follows Google's security protocols
  • Transmitted Analytics data is encrypted
  • No personal identifiable information is collected
  • Protected by device security settings (lock screen, etc.)

8. Internet Permission

The app uses internet permission for:

  • Firebase Analytics: Transmitting anonymized usage statistics
  • Future Features: Cloud backup, etc. (to be provided as optional features)

Golf record data is not transmitted over the internet.

9. Opt-Out of Analytics Tracking

Users can limit Analytics tracking through:

  • Android: Settings > Google > Ads > Reset advertising ID
  • iOS: Settings > Privacy > Tracking > Turn off "Allow Apps to Request to Track"

10. Changes to Privacy Policy

  • This privacy policy may be updated to reflect changes in laws or services
  • Changes will be announced through app update notifications
  • Significant changes will be announced at least 7 days in advance
